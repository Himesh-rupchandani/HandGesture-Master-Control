# Instructions for adding custom sound effects to HandGesture Master Control

You can add your own custom `.wav` sound files to this directory:

- `assets/sounds/play_pause.wav`  ← Played when you make a Fist ✊ (Play/Pause)
- `assets/sounds/seek_forward.wav` ← Played when you show 2 Fingers ✌️ (Seek +10s)
- `assets/sounds/seek_backward.wav` ← Played when you show 1 Finger ☝️ (Seek -10s)
- `assets/sounds/mute.wav`          ← Played when you pinch to Mute (0% Volume)

If no custom `.wav` file is present, the system automatically uses built-in **Cyberpunk Audio Beep Synthesis**!
